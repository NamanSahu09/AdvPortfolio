A modern, responsive digital portfolio website built with **React + Vite**, deployed on **AWS S3 + CloudFront**.  
This project is my personal portfolio where I showcase my skills, projects, and experiences, while also experimenting with **cloud deployment, animations, and performance optimization**.

---

## 🚀 Features

- 🎨 Responsive UI (works seamlessly across devices)  
- ⚡ Blazing-fast performance with React + Vite  
- ☁️ Deployed on AWS S3 + CloudFront with CDN distribution  
- 📩 Functional Contact Form using EmailJS  
- 🌀 Smooth GSAP Animations with ScrollTrigger  
- ⏳ Lazy Loading for optimized performance  
- 🔒 SEO-friendly & optimized for speed  

---

## 🛠️ Tech Stack

- **Frontend:** React, Vite, TailwindCSS  
- **Animations:** GSAP (ScrollTrigger)  
- **Cloud & Hosting:** AWS S3, CloudFront  
- **Other Tools:** EmailJS, Git, NPM

## 🏗️ Installation & Setup

Clone the repo and run it locally:

```bash
# Clone repo
git clone https://github.com/your-username/naman-portfolio.git
cd naman-portfolio

# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
